# Racarr

I am building this app because I didn't find good self hosted comic book collecting and tracking app.
This projcet will be alternative and hopefully better to Kapowarr, Mylarr etc. The main problem with that alternatives is, they support only torrent, or only getcomics.com website. Unfortunetely, no all comics exists at that sources. For now, this project's main source will be readallcomics.com because as far as i know, all comics exists there.

This project is still in very early stage. You can check progress at TODO.md
